# Licensing / ライセンス

## English

**Status: publication cleared on 2026-06-23. A formal open-source licence text has not yet
been added.** Until it is, treat the code as "source available": read it, learn from it,
file issues — but do not assume redistribution or commercial use is permitted.

Background. FACET was built in a work context. Tools created in the course of employment
are commonly the employer's intellectual property regardless of who typed the code or
where it is hosted; the question of ownership was therefore settled before this
repository was made public. This is a record of that process, not legal advice.

What was checked before publishing:

1. Ownership of the work product — settled.
2. Real data — hostnames, IP addresses, site names and any depiction of a real security
   architecture have been removed. The built-in samples use fictional names (`ACME-*`)
   and documentation address ranges (RFC 1918 / TEST-NET) only. Re-verify this before
   every release (see `docs/PUBLISHING.md`).
3. Licence choice — pending. MIT is the likely candidate; only the owner can grant it.
